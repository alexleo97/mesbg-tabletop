# Ground and terrain textures

These photographic textures come from [0 A.D.](https://play0ad.com/), the open-source historical
strategy game by [Wildfire Games](https://www.wildfiregames.com/). They are © Wildfire Games and
licensed under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
Some were derived by Wildfire Games from CGTextures materials, which CGTextures permitted them to
release under CC BY-SA.

We scaled them down to 512×512 and saved them as JPEG (`scripts/import-0ad-textures.py` does this).
These files, and any changes you make to them, stay under CC BY-SA 3.0; the rest of this project
is AGPL-3.0.
